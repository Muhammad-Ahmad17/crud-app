# Daily Independent Coding Ritual

This is the most important file in the repo for landing the job.

## Every day (90 minutes)

1. **Timer on.** Close ChatGPT / Cursor Agent / Stack Overflow for this block.
2. Open a **blank** `.cs` file or paper.
3. Solve **2–3** problems from the current week's CodingDrill stubs (`Problems.cs`).
4. **Rebuild from memory:** recreate yesterday's class/endpoint/SQL without looking.
5. If stuck **20+ minutes**, peek `Solutions.cs` / notes → close them → rewrite from scratch.
6. Log results in [`progress.md`](progress.md).

## Why this beats tutorials

CureMD CCAT + Systems coding rounds filter people who only follow along.
You already understand APIs from Node — the gap is **writing C# alone under time pressure**.
